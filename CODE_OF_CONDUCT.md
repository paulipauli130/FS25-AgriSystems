# Code of Conduct

## Our Commitment

The FS25 AgriSystems project aims to provide a welcoming, respectful and constructive environment for everyone involved.

We welcome contributors regardless of their experience level, background or role in the Farming Simulator community.

## Expected Behaviour

All community members are expected to:

- Treat others with respect and professionalism.
- Be constructive when providing feedback.
- Accept different opinions and technical approaches.
- Focus on improving the project rather than personal disagreements.
- Respect other people's work and contributions.
- Keep discussions relevant and helpful.

## Unacceptable Behaviour

The following behaviour is not acceptable:

- Harassment, discrimination or personal attacks.
- Insults, threats or intimidation.
- Deliberate disruption of discussions.
- Publishing private information without permission.
- Plagiarism or knowingly misrepresenting someone else's work.

## Enforcement

Project maintainers may remove inappropriate content, close discussions or restrict participation when necessary.

Serious or repeated violations may result in removal from the project community.

## Reporting Issues

If you experience or witness unacceptable behaviour, contact the project maintainers through the available GitHub communication channels.

Reports will be handled as fairly and confidentially as possible.

## Scope

This Code of Conduct applies to all project spaces, including:

- GitHub Issues
- Pull Requests
- Discussions
- Project-related communication channels

Thank you for helping keep FS25 AgriSystems a respectful and collaborative project.
